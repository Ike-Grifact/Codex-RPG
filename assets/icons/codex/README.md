# Atlas SVG — Codex RPG (primeira leva)
**Estado:** identidade visual implementada; mecânicas do SRD não foram alteradas.

- São 44 arquivos SVG independentes, de autoria original.
- Geometria vetorial `viewBox="0 0 64 64"`, traço de contorno, pontas e junções arredondadas. Arquivos editáveis e escaláveis.
- Indicador **DE**: fusão de Sowilo, Ansuz e Thurisaz em **uma cor exclusivamente azul** `#2369BB`. **Antecipar** mantém Ansuz `ᚨ` na mesma cor.
- Vida: gota de sangue; Integridade: escudo segmentado; armas/armaduras/elementos em contorno.
- **Constelações:** cada família do Codex Genético tem ícone próprio; as arestas continuam representando apenas afinidades temáticas, não requisitos ou efeitos.
- Os ícones não atribuem automaticamente Perícias, dados ou bônus.
- Veja [galeria](preview.html) após servir o diretório com um servidor local.
