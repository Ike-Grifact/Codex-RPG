# Decisão autoral · Reforço de dados antes da rolagem

**Estado: definido.** Decisão posterior à seção 0-Z.2 do SRD v0.49. Esta definição substitui, na elevação comum, a antiga mudança de categoria d4 → d6 → d10 → d12.

Antes de rolar, gaste **1 Coragem** para escolher um **d4, d6, d10 ou d12 já presente** na pilha de uma fonte legal. Acrescente **um dado temporário do mesmo tipo à mesma fonte**. Dado de equipamento já habilitado continua elegível. O original permanece na pilha, os dois dados são rolados separadamente e o Grau, os dados permanentes e as Perícias da ficha permanecem os mesmos. O reforço comum não acrescenta d20.

**Exemplo.** Influência G4 fornece 2d6 + 1d10. Apresentação G1 fornece 1d10. A pilha inicial tem 2d6 + 2d10. Ao reforçar Apresentação, a pilha passa a **2d6 + 3d10**. Conhecimentos e Práticas continuam recebendo o primeiro d12 no Grau 4 pela progressão normal.

Mantêm-se **um uso comum por rodada**, o limite de **nove dados rolados** e o máximo de **quatro mantidos**, com todas as exigências de retenção normais. O custo de reforçar o dado e o custo de manter um dado adicional são independentes. A decisão não altera custos específicos de ameaças, regras de dados extraordinários nem rolagens já gravadas.
