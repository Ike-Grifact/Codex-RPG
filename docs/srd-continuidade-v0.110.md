# Codex RPG — SRD de Continuidade v0.110

**Data:** 24/11/2026  
**Estado:** DEFINIDO — Saque Rápido custa 1 XP. Complementa v0.109.

- Requisitos: Agilidade 2 + Destreza 1 + Disciplina 2. Passiva; compra liberada por 1 XP.
- Inventário, acesso rápido e mãos são posições distintas; mesma carga física. Arma de uma mão ocupa uma; de duas mãos ocupa ambas; escudo empunhado ocupa uma. Empunhadura não definida no catálogo deve ser indicada na ficha, não inferida pelo peso. Preservar equipamento legado; confirmar empunhadura para novas mudanças.
- Saque/troca em combate: com a Perícia, reservar 1A antes dos demais usos de Antecipar; se não houver A, −2E. Sem a Perícia, saque do corpo para ataque −1E. Desarmar segue v0.109. Não criar regras de saque de bolsa sem a Perícia, coleta ou custos extras.
